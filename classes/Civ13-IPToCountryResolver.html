This function is used to get the country code of an IP address using the ip-api API.

public static Online(string $ip) : array<string|int, mixed>

The site will return a JSON object with the country code, region, and city of the IP address. The site will return a status of 429 if the request limit is exceeded (45 requests per minute). Returns a string in the format of 'CC->REGION->CITY'.
