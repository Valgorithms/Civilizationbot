HttpHandlerInterface.php : 29

Contract for the bot's built-in HTTP server router: a {@see HandlerInterface} collection of {@see HttpHandlerCallbackInterface} routes plus IP whitelisting, per-endpoint rate limiting and a generated help page. `handle()` resolves an incoming request to a route and returns its {@see HttpResponse}.
