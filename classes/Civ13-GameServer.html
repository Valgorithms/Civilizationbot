getRoundMessageId()

GameServer.php : 1308

Retrieves the round message ID.

public getRoundMessageId() : string|null

This method attempts to return the round message ID for the current instance.

  • If the property $round_message_id is already set, it returns its value.
  • Otherwise, it tries to load the value from a serialized array stored in a JSON file using the VarLoad method of the $civ13 object, with a filename based on the instance's key. If successful, it sets and returns the first element of the loaded array as $round_message_id.
  • If neither is available, it returns null.
Return values
string|null —

The round message ID if available, or null if not set or not found.

GameServer.php : 1555

Recalculates the ranking based on the awards data.

public recalculateRanking() : PromiseInterface
Tags
throws
MissingSystemPermissionException

If the awards or ranking files cannot be accessed or written to.

The function performs the following steps:

  1. Attempts to touch the awards and ranking files to ensure they are accessible.
  2. Reads the awards file line by line, skipping empty lines.
  3. Parses each line to extract user data and their corresponding medals.
  4. Calculates the score for each user based on their medals using predefined medal scores.
  5. Sorts the users by their scores in descending order.
  6. Writes the sorted ranking to the ranking file.
Return values
PromiseInterface —

A promise that resolves when the ranking has been successfully recalculated, or rejects with a MissingSystemPermissionException if there is an error accessing or writing to the necessary files.
