MessageHandlerCallbackInterface
The shape of a single `!command` callback registered on the {@see MessageHandlerInterface}: it receives the triggering {@see Message}, the matched command name and the pre-parsed/filtered message parts, and returns a {@see PromiseInterface} for its async work (or null when it does nothing).

setCallback()

MessageHandler.php : 101

Sets the callback to be used by the message handler.

public setCallback(Closure|callable $closure) : self

Validates the provided closure or callable using MessageHandlerCallback::validate(). If the closure is an object, it wraps it using Closure::fromCallable with the '__invoke' method. Otherwise, it wraps the callable directly. If the provided argument is not callable, it assigns it as-is to the callback property.

Validates that the given callback matches the expected parameter types defined in self::PARAMETER_TYPES.

public static validate(callable $callback[, bool $fatal = false ]) : callable|false

This method uses reflection to inspect the callback's parameters and ensures:

  • The callback has exactly the same number of parameters as defined in self::PARAMETER_TYPES.
  • Each parameter has a type hint.
  • Each parameter's type matches the corresponding type in self::PARAMETER_TYPES.
