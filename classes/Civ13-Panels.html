`/staffpanel` and `/playerpanel` — Components V2 dashboards that put the commonly-used bot actions one click away instead of behind a dozen slash commands. Both replies are ephemeral; every button re-checks permission on click, so a panel left open in scrollback can't be used by someone who shouldn't.

Staff: host / restart / kill each game server, panic bunker, ban & admin list refreshes, log cleanup, git pull / composer update. Player: verification status + a "Verify" modal, role resync, personal rank and ban lookup, live server status, campaign faction join.
